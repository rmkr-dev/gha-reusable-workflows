# Security Policy

## Supported versions

Security fixes apply to the latest tagged release and `main`.

## Reporting a vulnerability

Please open a **private** GitHub security advisory on this repository, or email the maintainer via the GitHub profile contact for `rmkr-dev`.

Do not file public issues for undisclosed vulnerabilities.

## Scope

This repository publishes reusable GitHub Actions workflows. Reports related to secret leakage, supply-chain weaknesses in workflow YAML, or unsafe defaults are in scope.
